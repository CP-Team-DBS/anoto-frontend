# Anoto Frontend
Anoto frontend repository - Mental Health Detection Application

Built with **React 19** and **Next.js 15** for modern, fast, and reliable user experience.

## Quick Start

```bash
# Clone repository
git clone https://github.com/CP-Team-DBS/anoto-frontend.git
cd anoto-frontend

# Install dependencies  
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

- **Framework**: Next.js 15 (App Router)
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript
- **Icons**: Lucide React
- **Build Tool**: Turbopack (Next.js 15)
